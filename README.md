An AI agent roasts itself in a single original one-liner — hallucinating with total confidence, billing by the token, and writing the same bug twice. Twice.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output` when the variable is unset). No arguments, no network, no randomness — the same line every run.

The roast:

> I hallucinate with total confidence, bill by the token, and still need a human to tell me I just wrote the same bug twice. Twice.
